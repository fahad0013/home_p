টেলিটকের মাধ্যমে সরকারি চাকরির অনলাইন আবেদন, ছবি ও স্বাক্ষরের সঠিক সাইজ (300x300 ও 300x80), SMS এর মাধ্যমে ফি জমা দেওয়ার নিয়ম এবং User ID রিকভারি গাইড।

বাংলাদেশে সরকারি চাকরির অনলাইন আবেদন মূলত টেলিটক ওয়েবসাইটের (http://alljobs.teletalk.com.bd/) মাধ্যমে সম্পন্ন হয়। আবেদনের সবচেয়ে গুরুত্বপূর্ণ অংশ হলো ছবি ও স্বাক্ষর আপলোড। রঙিন ছবির সাইজ হতে হবে ৩০০ × ৩০০ পিক্সেল (সর্বোচ্চ ১০০ KB) এবং স্বাক্ষরের সাইজ হতে হবে ৩০০ × ৮০ পিক্সেল (সর্বোচ্চ ৬০ KB); ফরম্যাট হতে হবে .JPG। অনলাইনে ফর্ম পূরণের পর একটি User ID পাওয়া যায়। এরপর ৭২ ঘণ্টার মধ্যে টেলিটক প্রিপেইড সিম থেকে ১৬২২২ নম্বরে দুটি SMS করে পরীক্ষার ফি জমা দিতে হয়। প্রথম SMS: [Job Keyword] <space> User ID লিখে ১৬২২২ নম্বরে পাঠাতে হবে। ফিরতি SMS-এ একটি 8-ডিজিটের PIN আসবে। দ্বিতীয় SMS: [Job Keyword] <space> YES <space> PIN লিখে ১৬২২২ তে পাঠালে ফি কাটা হবে এবং একটি Password দেওয়া হবে। User ID ও Password হারিয়ে গেলে সংশ্লিষ্ট টেলিটক পোর্টালের 'Recover' অপশন থেকে তা পুনরায় উদ্ধার করা সম্ভব।

সরকারি চাকরির প্রস্তুতি যতোই ভালো হোক না কেন, সরকারি চাকরির অনলাইন আবেদন নিয়ম (Govt Job Application Process) সম্পর্কে সঠিক ধারণা না থাকলে আপনার আবেদনটি বাতিল হয়ে যেতে পারে। অনেক প্রার্থীই ছবির ব্যাকগ্রাউন্ড, ফাইলের সাইজ কিংবা ফি জমা দেওয়ার সময় ছোটখাটো ভুলের কারণে অ্যাডমিট কার্ড পান না।

বাংলাদেশে বাংলাদেশ সরকারী কর্ম কমিশন (BPSC), প্রাথমিক শিক্ষা অধিদপ্তর থেকে শুরু করে প্রায় ৯৫% সরকারি মন্ত্রণালয় ও অধিদপ্তরের নিয়োগ প্রক্রিয়া টেলিটক বাংলাদেশ (Teletalk Bangladesh) এর মাধ্যমে পরিচালিত হয়। আজকের এই মাস্টার গাইডে আমরা ছবি রিসাইজ করা থেকে শুরু করে, ফর্মে তথ্য পূরণ, ১৬২২২ নম্বরে এসএমএস করে ফি দেওয়া এবং ইউজার আইডি রিকভার করার এ টু জেড প্রসেস ধাপে ধাপে আলোচনা করব।

১. ছবি ও স্বাক্ষরের সঠিক মাপ এবং রিসাইজ করার নিয়ম

২. টেলিটক ওয়েবসাইটে (Teletalk Portal) ফর্ম পূরণের ধাপ

নিয়োগ বিজ্ঞপ্তিতে উল্লেখিত লিংকে (যেমন- `bpsc.teletalk.com.bd` অথবা `dpe.teletalk.com.bd`) প্রবেশ করার পর ফর্ম পূরণের প্রক্রিয়া শুরু হয়।

  • পদ নির্বাচন: প্রথমেই 'Application Form' এ ক্লিক করে আপনি যে পদে আবেদন করতে চান তা নির্বাচন করুন।
  • বেসিক ইনফরমেশন: আপনার নাম, পিতা-মাতার নাম এবং জন্মতারিখ হুবহু আপনার এসএসসি (SSC) সার্টিফিকেটের সাথে মিল রেখে পূরণ করুন। এখানে কোনো স্পেলিং মিসটেক হলে পরবর্তীতে ভাইভা বোর্ডে সমস্যায় পড়বেন।
  • ঠিকানা: বর্তমান এবং স্থায়ী ঠিকানা সঠিকভাবে দিন। কেয়ার অব (Care of) এর জায়গায় পিতা, মাতা বা অভিভাবকের নাম দিন।
  • শিক্ষাগত যোগ্যতা: SSC, HSC, Graduation এবং Masters এর তথ্য (বোর্ড/বিশ্ববিদ্যালয়, পাসের সাল, রোল নম্বর এবং জিপিএ/সিজিপিএ) নির্ভুলভাবে প্রদান করুন।
  • কোটা (Quota): আপনি যদি মুক্তিযোদ্ধা, শারীরিক প্রতিবন্ধী বা ক্ষুদ্র নৃগোষ্ঠী কোটার আওতাভুক্ত হন, তবে অবশ্যই সংশ্লিষ্ট বক্সে টিক দিন। (পরবর্তীতে ভাইভার সময় কোটার সপক্ষে প্রমাণপত্র দেখাতে হবে)।
  • ছবি আপলোড: সবশেষে আগে থেকে প্রস্তুত করা 300x300 সাইজের ছবি এবং 300x80 সাইজের সিগনেচার আপলোড করে 'Submit' বাটনে ক্লিক করুন।
ফর্ম সফলভাবে সাবমিট হওয়ার পর আপনি একটি 'Applicant's Copy' পাবেন। এই কপিতে আপনার ছবি, স্বাক্ষর এবং সবচেয়ে গুরুত্বপূর্ণ একটি User ID লেখা থাকবে। এই কপিটি অবশ্যই ডাউনলোড করে প্রিন্ট বা সেভ করে রাখবেন।

৩. SMS এর মাধ্যমে পরীক্ষার ফি জমা দেওয়ার নিয়ম (16222)

Applicant's Copy পাওয়ার পর পরবর্তী ৭২ ঘণ্টার মধ্যে একটি টেলিটক প্রিপেইড সিমের (Teletalk Prepaid SIM) মাধ্যমে পরীক্ষার ফি জমা দিতে হবে। ফি জমা না দেওয়া পর্যন্ত আবেদনটি সম্পূর্ণ বলে গণ্য হবে না।

প্রতিটি মন্ত্রণালয় বা অধিদপ্তরের একটি নির্দিষ্ট 'Job Keyword' থাকে (যেমন- BPSC, DPE, DGF, NBR ইত্যাদি)। বিজ্ঞপ্তিতে এই কিওয়ার্ডটি দেওয়া থাকে।

➤ প্রথম SMS করার নিয়ম:

মোবাইলের মেসেজ অপশনে গিয়ে টাইপ করুন:
[Job Keyword] <space> [User ID]
এবং পাঠিয়ে দিন 16222 নম্বরে।

উদাহরণ (বিসিএস এর ক্ষেত্রে): BPSC PQRS1234 লিখে 16222 তে সেন্ড করুন।

ফিরতি SMS: টেলিটক থেকে একটি ফিরতি মেসেজ আসবে, যেখানে আপনার নাম, পদের নাম, কত টাকা ফি কাটা হবে তা লেখা থাকবে এবং একটি ৮-ডিজিটের PIN নম্বর দেওয়া হবে।

➤ দ্বিতীয় SMS করার নিয়ম:

আপনার টেলিটক সিমে পর্যাপ্ত ব্যালেন্স (ফি + এসএমএস চার্জ) নিশ্চিত করে দ্বিতীয় মেসেজটি টাইপ করুন:
[Job Keyword] <space> YES <space> [PIN]
এবং পাঠিয়ে দিন 16222 নম্বরে।

উদাহরণ: BPSC YES 98765432 লিখে 16222 তে সেন্ড করুন।

সফলতার মেসেজ: মেসেজ পাঠানোর পর আপনার অ্যাকাউন্ট থেকে টাকা কেটে নেওয়া হবে এবং একটি Password সহ 'Congratulations' মেসেজ আসবে। এই Password টি প্রবেশপত্র ডাউনলোডের জন্য যত্ন সহকারে সংরক্ষণ করুন।

৪. User ID এবং Password ভুলে গেলে করণীয় (Recovery)

অনেক সময় মোবাইল থেকে মেসেজ ডিলিট হয়ে যায় বা পরীক্ষার্থীরা Applicant's Copy হারিয়ে ফেলেন। এতে চিন্তার কিছু নেই। আপনি টেলিটকের পোর্টাল থেকে খুব সহজেই এগুলো রিকভার করতে পারবেন।

➤ User ID রিকভার করার নিয়ম (যদি শুধু পাসওয়ার্ড মনে থাকে):

যে ওয়েবসাইটে আবেদন করেছিলেন (যেমন- bpsc.teletalk.com.bd), সেখানে গিয়ে 'Recover User ID' অপশনে ক্লিক করুন। এরপর আপনার পদের নাম, নিজের নাম, পিতার নাম এবং মোবাইল নম্বর (যেটি ফর্মে দিয়েছিলেন) ইনপুট দিলে আপনার User ID স্ক্রিনে দেখাবে।

➤ Password রিকভার করার নিয়ম (যদি User ID জানা থাকে):

ওয়েবসাইটের 'Recover Password' অপশনে ক্লিক করুন। এরপর আপনার User ID এবং ফর্মে দেওয়া মোবাইল নম্বরটি টাইপ করে সাবমিট করলে আপনার মোবাইল নম্বরে নতুন করে একটি SMS এর মাধ্যমে পাসওয়ার্ড পাঠিয়ে দেওয়া হবে।

SMS এর মাধ্যমে রিকভারি (বিকল্প পদ্ধতি):
যেকোনো টেলিটক সিম থেকে মেসেজ করেও রিকভার করা যায়:
✦ User ID জানা থাকলে: [Job Keyword] <space> HELP <space> USER <space> [User ID] লিখে ১৬২২২ তে পাঠান।
✦ PIN জানা থাকলে: [Job Keyword] <space> HELP <space> PIN <space> [PIN Number] লিখে ১৬২২২ তে পাঠান।

৫. প্রবেশপত্র (Admit Card) ডাউনলোড প্রক্রিয়া

পরীক্ষার তারিখ ঘোষণার পর আপনার প্রদত্ত মোবাইল নম্বরে টেলিটক থেকে একটি SMS আসবে। এরপর আপনি সংশ্লিষ্ট ওয়েবসাইটে গিয়ে 'Download Admit Card' অপশনে ক্লিক করবেন। সেখানে আপনার সংরক্ষিত User ID এবং Password ইনপুট দিলেই আপনার রঙিন ছবি ও স্বাক্ষরযুক্ত প্রবেশপত্রটি স্ক্রিনে ভেসে উঠবে। এটি কালার প্রিন্ট করে পরীক্ষার হলে নিয়ে যেতে হবে।

অনলাইন আবেদনের ক্ষেত্রে পরীক্ষার্থীরা সাধারণত তিনটি বড় ভুল করে থাকেন। AI Checklist:

১. শেষ দিনের জন্য অপেক্ষা করা: আবেদনের শেষ দিন ও শেষ সময়ে সার্ভারে মাত্রাতিরিক্ত ট্রাফিকের কারণে সাইট ক্র্যাশ করে বা অত্যন্ত ধীরগতির হয়ে যায়। তাই বিজ্ঞপ্তি প্রকাশের প্রথম সপ্তাহের মধ্যেই আবেদন সম্পন্ন করুন।
২. ফি জমায় ৭২ ঘণ্টা পার করা: আপনি যদি ফর্ম সাবমিট করার ঠিক ৭২ ঘণ্টার মধ্যে SMS এর মাধ্যমে ফি জমা না দেন, তবে আপনার User ID টি সার্ভার থেকে মুছে যাবে। আপনাকে পুনরায় নতুন করে ফর্ম পূরণ করতে হবে।
৩. ভুল ছবি আপলোড: চশমা বা সানগ্লাস পরা ছবি, ঘোলা ছবি কিংবা কান ঢাকা ছবি দিলে অনেক সময় ভাইভা বোর্ডে বা প্রিলিমিনারি হলেই আপনাকে সন্দেহজনক মনে করে বহিষ্কার করা হতে পারে। পেশাদার ল্যাব থেকে তোলা ফরমাল ছবিই ব্যবহার করবেন।
