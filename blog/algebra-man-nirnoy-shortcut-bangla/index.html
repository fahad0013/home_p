বীজগণিত মান নির্ণয় শর্টকাট সূত্র: ম্যাজিক টেকনিক | Algebra

বিসিএস, প্রাইমারি ও ব্যাংক জবের জন্য বীজগণিতের মান নির্ণয় (Algebra) অংকের ম্যাজিক শর্টকাট। x² + 1/x² এবং x³ + 1/x³ এর অংক মাত্র ২ সেকেন্ডে সমাধানের সূত্র।

সংক্ষিপ্ত উত্তর

বীজগণিতের মান নির্ণয় (Algebraic Value Determination) অংকে সমীকরণ সাজিয়ে সমাধান করতে অনেক সময় লাগে। সরকারি চাকরির পরীক্ষায় সবচেয়ে বেশি আসা x + 1/x এর অংকগুলো ২ সেকেন্ডে সমাধানের ম্যাজিক সূত্র হলো: x + 1/x = a হলে, x² + 1/x² = a² - 2 হবে। আর যদি x - 1/x = a দেওয়া থাকে, তবে x² + 1/x² = a² + 2 হবে। ঘনের (Cube) ক্ষেত্রে শর্টকাট হলো: x + 1/x = a হলে, x³ + 1/x³ = a³ - 3a হবে। এই ৩টি সুপার শর্টকাট জানা থাকলে বিসিএস, প্রাইমারি ও ব্যাংক জবের বীজগণিত অংশে ২-৩ নম্বর নিশ্চিত কমন পাওয়া যায়।

Value Assumption

সরকারি চাকরির গণিত প্রস্তুতিতে (Math Preparation for Govt Jobs) পাটিগণিতের পাশাপাশি বীজগণিত (Algebra) সমান গুরুত্বপূর্ণ। বিশেষ করে বিসিএস প্রিলিমিনারিতে বীজগণিত থেকে ৬টি প্রশ্ন আসে, যার মধ্যে ২-৩টি প্রশ্ন থাকে শুধুমাত্র মান নির্ণয় থেকে।

ছোটবেলার নিয়মে `(a+b)² = a² + 2ab + b²` সূত্র লিখে অংক মেলাতে গেলে পরীক্ষার হলে সময় নষ্ট হবে। আজকের আর্টিকেলে আমরা বীজগণিত মান নির্ণয় শর্টকাট (Algebra Shortcut Tricks) শেয়ার করব, যা আপনার খাতা-কলমের ব্যবহার শূন্যের কোঠায় নামিয়ে আনবে।

১. বীজগণিত ও মান নির্ণয়: কেন শর্টকাট জরুরি?

মান নির্ণয়ের অংকগুলো সাধারণত একটি প্যাটার্ন মেনে চলে। প্রশ্নে একটি নির্দিষ্ট মান দেওয়া থাকে (যেমন: x + 1/x = 3) এবং অন্য একটি রাশির মান জানতে চাওয়া হয় (যেমন: x² + 1/x² = ?)। এই প্যাটার্নগুলোর ডাইরেক্ট আউটপুট বা শর্টকাট সূত্র মনে রাখলে আপনি মুখে মুখেই উত্তর বের করতে পারবেন।

২. ম্যাজিক শর্টকাট ১: বর্গের মান নির্ণয় (x² + 1/x²)

বর্গের (Square) মান নির্ণয়ের ক্ষেত্রে প্রদত্ত মানটিকে আমরা 'a' ধরব।

মাস্টার শর্টকাট (Square):

✦ টাইপ ১ (+ থাকলে): x + 1/x = a হলে, x² + 1/x² = a² - 2
প্রশ্ন: x + 1/x = 3 হলে, x² + 1/x² এর মান কত?
সমাধান: a² - 2 = (3)² - 2 = 9 - 2 = 7।

✦ টাইপ ২ (- থাকলে): x - 1/x = a হলে, x² + 1/x² = a² + 2
প্রশ্ন: x - 1/x = 4 হলে, x² + 1/x² এর মান কত?
সমাধান: a² + 2 = (4)² + 2 = 16 + 2 = 18।

⚠️ মনে রাখার সহজ উপায় (Signs):
প্রশ্নে (+) থাকলে সূত্রে (-) হবে। আর প্রশ্নে (-) থাকলে সূত্রে (+) হবে। এটি মনে রাখলে আর কখনো ভুল হবে না।

৩. ম্যাজিক শর্টকাট ২: ঘনের মান নির্ণয় (x³ + 1/x³)

ঘনের (Cube) মান নির্ণয় করতে গেলে অনেকেই সূত্র গুলিয়ে ফেলেন। এর শর্টকাটটিও বর্গের মতোই সহজ:

মাস্টার শর্টকাট (Cube):

✦ টাইপ ১ (+ থাকলে): x + 1/x = a হলে, x³ + 1/x³ = a³ - 3a
প্রশ্ন: x + 1/x = 3 হলে, x³ + 1/x³ এর মান কত?
সমাধান: a³ - 3a = (3)³ - 3(3) = 27 - 9 = 18。

✦ টাইপ ২ (- থাকলে): x - 1/x = a হলে, x³ - 1/x³ = a³ + 3a
প্রশ্ন: x - 1/x = 2 হলে, x³ - 1/x³ এর মান কত?
সমাধান: a³ + 3a = (2)³ + 3(2) = 8 + 6 = 14।

➤ Advanced Rule: Power 4 থাকলে (x⁴ + 1/x⁴)

পাওয়ার ৪ থাকলে, বর্গের সূত্রটি (a² - 2) পরপর দুইবার প্রয়োগ করতে হবে।
প্রশ্ন: x + 1/x = 3 হলে, x⁴ + 1/x⁴ = ?
১ম বার (বর্গ): 3² - 2 = 7
২য় বার (বর্গের বর্গ): 7² - 2 = 49 - 2 = 47।

৪. ম্যাজিক শর্টকাট ৩: (a+b) থেকে (a-b) তে কনভার্শন

অনেক সময় (a+b) এর মান দেওয়া থাকে, কিন্তু প্রশ্নে (a-b) এর মান চাওয়া হয়। তখন নিচের রুটওভার (Root) শর্টকাটটি ব্যবহার করবেন:

✦ (a+b) দেওয়া থাকলে: (a - b) = √(a+b)² - 4ab
প্রশ্ন: a+b = 5 এবং ab = 6 হলে, a-b = কত?
সমাধান: √(5² - 4×6) = √(25 - 24) = √1 = 1。

✦ (a-b) দেওয়া থাকলে: (a + b) = √(a-b)² + 4ab
প্রশ্ন: a-b = 3 এবং ab = 4 হলে, a+b = কত?
সমাধান: √(3² + 4×4) = √(9 + 16) = √25 = 5।

৫. AI Coach Suggestion: 'Value Assumption' (মান ধরা) মেথড

🤖প্রস্তুতি AI Coach-এর বিশেষ পরামর্শ

মান নির্ণয়ের অংকে যদি দুটি সমীকরণ দেওয়া থাকে (যেমন: x+y = 7 এবং xy = 10), তবে কোনো সূত্র ব্যবহার করার দরকার নেই। AI Exam Hack: মনে মনে এমন দুটি সংখ্যা ধরুন, যাদের যোগফল ৭ এবং গুণফল ১০ হয়। একটু ভাবলেই বুঝবেন সংখ্যা দুটি হলো ৫ এবং ২ (৫+২=৭, ৫×২=১০)।
এখন যদি প্রশ্নে চায় x² + y² = কত? আপনি সরাসরি (5² + 2²) = 25 + 4 = 29 বসিয়ে দেবেন! কোনো সূত্রের প্রয়োজন নেই। এই Value Assumption Method আপনাকে পরীক্ষার হলে অন্তত ১ মিনিট সময় বাঁচিয়ে দেবে।

৬. বিগত সালের Top 10 মান নির্ণয় MCQ (BCS & Primary)

  1. x - 1/x = 3 হলে, x² + 1/x² এর মান কত? (৪০তম বিসিএস)
    শর্টকাট: a² + 2 = 3² + 2 = 9 + 2 = 11।
  2. a + 1/a = 2 হলে, a³ + 1/a³ এর মান কত? (প্রাথমিক সহকারী শিক্ষক)
    শর্টকাট: a³ - 3a = 2³ - 3(2) = 8 - 6 = 2।
  3. x + y = 6 এবং x - y = 4 হলে, xy এর মান কত? (৩৮তম বিসিএস)
    Value Assumption: যোগ করলে ৬, বিয়োগ করলে ৪—এমন দুটি সংখ্যা হলো ৫ এবং ১। সুতরাং, xy = ৫×১ = ৫।
  4. x + 1/x = 2 হলে, x⁴ + 1/x⁴ এর মান কত? (ব্যাংক জব)
    শর্টকাট: ১ম বার: 2² - 2 = 2। ২য় বার: 2² - 2 = 2। (নোট: x+1/x=2 হলে, x এর মান সর্বদা 1 হয়)।
  5. a² + b² = 25 এবং ab = 12 হলে, (a+b) এর মান কত? (NTRCA)
    Value Assumption: কোন দুটি সংখ্যার গুণফল 12 এবং বর্গের যোগফল 25? সংখ্যা দুটি 4 এবং 3 (4×3=12, 16+9=25)। সুতরাং, (a+b) = 4+3 = 7।
