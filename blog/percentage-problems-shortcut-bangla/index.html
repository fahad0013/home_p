শতকরা অংক শর্টকাট টেকনিক ও বিগত সালের প্রশ্ন সমাধান | BCS

সরকারি চাকরির (বিসিএস, প্রাইমারি, ব্যাংক) জন্য শতকরা অংক (Percentage) শর্টকাট নিয়মে সমাধানের ম্যাজিক টেকনিক। পাশ-ফেল ও মূল্য বৃদ্ধির বিগত সালের কমন MCQ।

সংক্ষিপ্ত উত্তর

শতকরা (Percentage) হলো পাটিগণিতের মূল ভিত্তি, যা একটি ভগ্নাংশ যার হর সবসময় ১০০। সরকারি চাকরির পরীক্ষায় (বিসিএস, প্রাইমারি, ব্যাংক) শতকরা থেকে সরাসরি ২-৩টি প্রশ্ন আসে। এর সবচেয়ে কমন ৩টি শর্টকাট হলো: ১. মূল্য বৃদ্ধির অংকে (যেমন চিনির দাম): কমানোর হার = [বৃদ্ধির হার / (১০০ + বৃদ্ধির হার)] × ১০০। ২. পাশ-ফেল অংকে: মোট শিক্ষার্থী = (১ম বিষয়ে পাশ + ২য় বিষয়ে পাশ - উভয় বিষয়ে পাশ) + উভয় বিষয়ে ফেল। ৩. পরপর দুইবার বৃদ্ধি বা হ্রাসের অংকে (যেমন আয়তক্ষেত্রের ক্ষেত্রফল): A + B + (AB/100)। এই শর্টকাটগুলো ব্যবহার করে ঐকিক নিয়ম ছাড়াই ৫-১০ সেকেন্ডে উত্তর বের করা যায়।

সরকারি চাকরির গণিত প্রস্তুতিতে (Math Preparation for Govt Jobs) সবচেয়ে সোনালী অধ্যায় হলো শতকরা (Percentage)। আপনি যদি শতকরা ভালো করে না বোঝেন, তবে লাভ-ক্ষতি (Profit & Loss) এবং সুদকষার (Simple Interest) অংক করতে গিয়ে খাবি খাবেন।

পরীক্ষার হলে ক্যালকুলেটর নিষিদ্ধ থাকে। তাই শতকরা অংক শর্টকাট বাংলায় (Percentage Shortcut in Bengali) জানা থাকলে যে অংক করতে ৩ মিনিট লাগে, তা মাত্র ১০ সেকেন্ডে সমাধান করা সম্ভব। আজকের আর্টিকেলে আমরা শতকরার ম্যাজিক চার্ট ও সুপার ৩টি শর্টকাট শেয়ার করব।

২. শর্টকাট ১: মূল্য বৃদ্ধি বা হ্রাসের অংক (চিনির দাম)

"চিনির মূল্য ২০% বৃদ্ধি পেল। এতে একটি পরিবারকে চিনির ব্যবহার শতকরা কত কমাতে হবে যাতে খরচ বৃদ্ধি না পায়?"—এই প্রশ্নটি বিসিএস ও প্রাইমারিতে অগণিতবার এসেছে।

ম্যাজিক সূত্র (মূল্য বৃদ্ধি পেলে):

ব্যবহার কমানোর হার = [বৃদ্ধির হার / (১০০ + বৃদ্ধির হার)] × ১০০

সমাধান:
= [২০ / (১০০ + ২০)] × ১০০
= (২০ / ১২০) × ১০০
= (১ / ৬) × ১০০ = ১৬.৬৭% বা ১৬ ২/৩%।
⚠️ ম্যাজিক সূত্র (মূল্য হ্রাস পেলে):

ব্যবহার বাড়ানোর হার = [হ্রাসের হার / (১০০ - হ্রাসের হার)] × ১০০
যেমন: তেলের মূল্য ২৫% কমে গেলে ব্যবহার কত বাড়াতে হবে?
সমাধান: [২৫ / (১০০ - ২৫)] × ১০০ = (২৫ / ৭৫) × ১০০ = (১/৩) × ১০০ = ৩৩.৩৩%।

৩. শর্টকাট ২: পাশ-ফেল ও পরীক্ষার্থীর অংক (Venn Diagram Logic)

আরেকটি কমন প্রশ্ন: "বাংলায় ৬০% পাশ করল, অঙ্কে ৭০% পাশ করল এবং উভয় বিষয়ে ২০% ফেল করল। উভয় বিষয়ে কতজন পাশ করল?"

মাস্টার শর্টকাট (Total = 100):

১০০ = (১ম বিষয়ে পাশ + ২য় বিষয়ে পাশ - উভয় বিষয়ে পাশ) + উভয় বিষয়ে ফেল

সমাধান: ধরি, উভয় বিষয়ে পাশ = x
১০০ = (৬০ + ৭০ - x) + ২০
১০০ = ১৩০ - x + ২০
১০০ = ১৫০ - x
x = ১৫০ - ১০০ = ৫০%। (উভয় বিষয়ে ৫০% পাশ করেছে)।

৪. শর্টকাট ৩: পরপর দুইবার পরিবর্তন (ক্ষেত্রফলের অংক)

বিসিএস ও ব্যাংক জবে ক্ষেত্রফল বৃদ্ধি বা হ্রাসের অংক প্রায়ই আসে: "একটি আয়তক্ষেত্রের দৈর্ঘ্য ১০% বৃদ্ধি এবং প্রস্থ ১০% হ্রাস পেলে ক্ষেত্রফলের কী পরিবর্তন হবে?"

সাকসেসিভ সূত্র (Successive Percentage):

A + B + (AB / ১০০)
(নিয়ম: বৃদ্ধি পেলে মান +, হ্রাস পেলে মান - হবে)

সমাধান:
দৈর্ঘ্য (A) = +১০
প্রস্থ (B) = -১০
মোট পরিবর্তন = (+১০) + (-১০) + [(১০ × -১০) / ১০০]
= ০ + (-১০০ / ১০০)
= -১।
যেহেতু উত্তর নেগেটিভ (-১) এসেছে, তাই ১% হ্রাস পাবে।

৫. AI Coach Suggestion: 'Assume 100' ও 'Fraction' মেথড

🤖প্রস্তুতি AI Coach-এর বিশেষ পরামর্শ

শতকরার অংকে সমীকরণ সাজাতে গিয়ে X ধরলে আপনার ২ মিনিট সময় নষ্ট হবে। AI Exam Hack: প্রশ্নে যদি কোনো নির্দিষ্ট সংখ্যা (যেমন: ৫০০ জন, ২০০ টাকা) না দেওয়া থাকে এবং শুধু % চাওয়া হয়, তবে মূল সংখ্যাটিকে সবসময় ১০০ ধরে নিবেন (Assume 100 Method)। আর যদি প্রশ্নে ৩৩.৩৩% বা ১২.৫% এর মতো জটিল সংখ্যা থাকে, তবে চার্ট অনুযায়ী তাকে ভগ্নাংশে (১/৩ বা ১/৮) রূপান্তর করে নিবেন। এতে ক্যালকুলেটর ছাড়াই ১০ সেকেন্ডে হিসাব মিলে যাবে। প্রস্তুতি অ্যাপের (Prostuti App) মক টেস্টে আজই এই মেথডটি প্র্যাকটিস করুন।

৬. বিগত সালের Top 10 শতকরা MCQ (BCS & Primary)

  1. চিনির মূল্য ২৫% বৃদ্ধি পেলে, একটি পরিবারকে চিনির ব্যবহার শতকরা কত কমাতে হবে? (৪০তম বিসিএস)
    শর্টকাট: (২৫ / ১২৫) × ১০০ = (১/৫) × ১০০ = ২০%।
  2. একটি আয়তক্ষেত্রের দৈর্ঘ্য ২০% বৃদ্ধি ও প্রস্থ ১০% হ্রাস পেলে ক্ষেত্রফলের কী পরিবর্তন হবে? (প্রাথমিক সহকারী শিক্ষক)
    শর্টকাট: ২০ - ১০ + [(২০ × -১০) / ১০০] = ১০ - ২ = ৮% বৃদ্ধি।
  3. কোনো পরীক্ষায় ২০% পরীক্ষার্থী গণিতে এবং ৩০% ইংরেজিতে ফেল করল। উভয় বিষয়ে ১৩% ফেল করলে শতকরা কতজন পাস করল? (৩৮তম বিসিএস)
    শর্টকাট (ভেনচিত্র): শুধু গণিতে ফেল = (২০-১৩) = ৭%। শুধু ইংরেজিতে ফেল = (৩০-১৩) = ১৭%। মোট ফেল = ৭ + ১৭ + ১৩ = ৩৭%।
    পাস = ১০০ - ৩৭ = ৬৩%।
  4. ১৪৪ কোন সংখ্যার ৪০%? (NTRCA)
    শর্টকাট: সংখ্যাটি = ১৪৪ × (১০০ / ৪০) = ১৪৪ × ২.৫ = ৩৬০।
  5. একটি প্যান্টের দাম ২০% কমানোর পর আবার ২০% বাড়ানো হলো। দামের কী পরিবর্তন হলো? (ব্যাংক জব)
    শর্টকাট: -২০ + ২০ + [(-২০ × ২০) / ১০০] = ০ - ৪ = ৪% কমবে।
