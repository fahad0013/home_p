Security+ Practice Questions: General Security Concepts

By Prostutii Editorial • Last Verified: 2026-11-18
⚡Direct Answer / Summary
Use this set of 20 original General Security Concepts questions to test control types, the CIA triad, AAA, zero trust, change management and cryptography. Allow about one minute per question, check every explanation, and note which topics you miss. They are practice questions written for learning, not real exam content.

Last verified: November 18, 2026, against CompTIA’s Security+ V7 and Security+ V8 pages.

General Security Concepts is the foundation domain of Security+. It carries 12% of SY0-701 and 16% of SY0-801, according to CompTIA’s published weights, and its ideas show up inside every other domain. If you understand why a control is preventive rather than corrective, or why a digital signature provides something a hash cannot, the rest of the exam gets easier.

This set has 8 easy questions, 8 medium questions and 4 scenario questions. Each answer explains why the correct choice is right and why every other option is wrong. Every question covers a topic that CompTIA’s published summaries list for SY0-701, SY0-801 or both, so check the official objectives for the version you plan to take.

Key takeaways
✦ The real exam has a maximum of 90 questions in 90 minutes, so about one minute per question is a good practice pace.
✦ Learn the control categories (technical, managerial, operational, physical) separately from the control types (preventive, deterrent, detective, corrective, compensating, directive).
✦ Hashing checks integrity, digital signatures add non-repudiation, and encryption protects confidentiality.
✦ When two answers look right, find the detail in the question that decides between them.
✦ Review your wrong answers by topic, not by question number.

How to use this practice set

  1. Set a timer. Give yourself about 20 minutes for all 20 questions, or work in the three blocks below.
  2. Answer before you open the explanation. Commit to a choice first, then check.
  3. Read every explanation, including for questions you got right. The notes on wrong options are where the exam-style distinctions live.
  4. Write down the topic of every question you miss, then use the study map near the end of this page.
Pitfall: memorizing answers instead of reasons.
If you can only recall that “B” was correct, you will miss the same idea when it is reworded. Be able to say, in one sentence, what detail in the question rules out each wrong option.

Questions 1 to 8: warm-up

Question 1Easy

An organization places prominent warning signs and visible security cameras outside its data center perimeter. Which of the following security control types is primarily implemented by this measure?

A. Corrective control
B. Deterrent control
C. Compensating control
D. Detective control
Show answer and explanation

Correct answer: B. Deterrent controls are designed to discourage potential attackers from attempting a security violation by making them aware of the consequences or surveillance.

Why the other options are wrong:

  • A. Corrective controls remediate or restore systems after an incident has occurred (e.g., restoring backups or patching).
  • C. Compensating controls are alternative safeguards deployed when a primary control cannot be implemented.
  • D. While cameras have detective capabilities once recording, prominent warning banners and visible cameras are primarily classified as deterrent controls intended to discourage unauthorized actions before they occur.
Question 2Easy

A systems engineer configures firewall access control lists (ACLs) to block all inbound traffic on unapproved network ports. Under which control category is this safeguard classified?

A. Managerial control
B. Operational control
C. Technical control
D. Physical control
Show answer and explanation

Correct answer: C. Technical controls (also known as logical controls) are implemented through hardware, software, or firmware systems, such as firewalls, ACLs, and encryption.

Why the other options are wrong:

  • A. Managerial controls are administrative and strategic guidelines set by management, such as security policies and risk assessments.
  • B. Operational controls are day-to-day procedures performed by humans, such as user onboarding, incident response training, and security awareness.
  • D. Physical controls protect the real-world perimeter and assets, such as fences, locks, badges, and environmental sensors.
Question 3Easy

A financial institution deploys redundant power supplies, RAID arrays, and geo-replicated database clusters. Which pillar of the CIA triad is directly protected by these mechanisms?

A. Confidentiality
B. Integrity
C. Availability
D. Authentication
Show answer and explanation

Correct answer: C. Availability ensures that systems, services, and data are accessible to authorized users whenever needed. Redundancy, fault tolerance, and RAID arrays preserve availability against hardware failures.

Why the other options are wrong:

  • A. Confidentiality ensures that sensitive information is shielded from unauthorized access or disclosure (typically achieved via encryption and access controls).
  • B. Integrity guarantees that data has not been altered, tampered with, or destroyed in an unauthorized manner (typically verified with hashes and signatures).
  • D. Authentication is part of the AAA framework to verify user identity, not one of the three primary pillars of the CIA triad.
Question 4Easy

When a user logs into an enterprise portal, which component of the AAA framework is responsible for determining what specific resources, folders, and applications that user is permitted to access?

A. Authentication
B. Authorization
C. Accounting
D. Auditing
Show answer and explanation

Correct answer: B. Authorization defines the permissions and access rights granted to an authenticated identity, determining what files, directories, or functions the user can execute.

Why the other options are wrong:

  • A. Authentication proves identity (e.g., verifying a password or biometrics), but it does not specify what resources the user can modify once validated.
  • C. Accounting tracks user activity, resource consumption, and session duration for billing, auditing, and compliance purposes.
  • D. Auditing is the programmatic or manual inspection of recorded event logs to review compliance and investigate anomalies.
Question 5Easy

A legal document is sent electronically between two corporations. Which cryptographic service provides non-repudiation, preventing the sender from claiming they never sent the message?

A. Symmetric stream cipher encryption
B. Cryptographic hash generation (SHA-256)
C. Digital signature using the sender’s private key
D. Asymmetric encryption using the recipient’s public key
Show answer and explanation

Correct answer: C. A digital signature (hash encrypted with the sender’s private key) guarantees both message integrity and non-repudiation, because only the sender possesses the unique private key required to generate that signature.

Why the other options are wrong:

  • A. Symmetric encryption uses a shared secret known to both parties, meaning either party could have created the ciphertext, failing to provide non-repudiation.
  • B. A cryptographic hash verifies integrity (that data was not altered), but does not prove who authored the original message.
  • D. Encrypting with the recipient’s public key provides confidentiality for the recipient, but anyone possessing the recipient’s public key could have crafted the message.
Question 6Easy

What is the primary operational advantage of symmetric encryption (such as AES-GCM) compared to asymmetric encryption (such as RSA)?

A. Symmetric algorithms eliminate the need to distribute keys securely
B. Symmetric encryption provides significantly faster throughput with less computational overhead
C. Symmetric encryption inherently provides digital signatures and identity verification
D. Symmetric ciphers use separate public and private mathematical key pairs
Show answer and explanation

Correct answer: B. Symmetric encryption algorithms are orders of magnitude faster and require far less CPU power than asymmetric algorithms, making them the standard choice for bulk data encryption.

Why the other options are wrong:

  • A. Key distribution is the primary disadvantage of symmetric encryption, as the shared secret key must be safely shared out-of-band or via an asymmetric exchange.
  • C. Symmetric encryption cannot provide digital signatures or non-repudiation because both sender and receiver possess the exact same shared key.
  • D. Asymmetric encryption uses key pairs (public and private keys); symmetric encryption uses a single shared secret key.
Question 7Easy

Before applying a major firmware patch to core network routing hardware, which component of a formal change management plan is essential to reverse the changes if the update causes critical outages?

A. Standard operating procedure (SOP)
B. Backout / Rollback plan
C. Service level agreement (SLA)
D. Request for comment (RFC)
Show answer and explanation

Correct answer: B. A backout (or rollback) plan outlines the exact technical steps, configurations, and backups necessary to restore systems to their previous stable baseline if a change fails.

Why the other options are wrong:

  • A. An SOP describes routine everyday tasks, not the disaster recovery steps specific to an abortive production patch.
  • C. An SLA is a contractual agreement defining expected service uptime and response benchmarks between a vendor and customer.
  • D. An RFC is a proposal or standards document, not a remediation procedure for failing changes.
Question 8Easy

Which foundational philosophy defines the Zero Trust architecture model (ZTA)?

A. Implicitly trust all devices connecting from within the corporate LAN perimeter
B. Never trust, always verify every access request regardless of network location
C. Rely entirely on perimeter firewalls and VPN tunnels to validate user authorization
D. Grant domain administrators unrestricted, persistent access across all endpoints
Show answer and explanation

Correct answer: B. Zero Trust operates on the principle of "never trust, always verify." Every user, device, and network transaction must be explicitly authenticated, authorized, and continuously monitored, whether inside or outside the network.

Why the other options are wrong:

  • A. Implicit trust inside the local LAN is the legacy perimeter model that Zero Trust explicitly eliminates.
  • C. Perimeter firewalls and VPNs represent traditional castle-and-moat security; Zero Trust moves inspection to the individual resource and identity level.
  • D. Zero Trust enforces the principle of least privilege and just-in-time access, rejecting persistent unrestricted administrator privileges.

Questions 9 to 16: core concepts

Three questions in this block (9, 11 and 15) have a tempting second answer. Read the explanation to see which detail decides between them.

Question 9Medium

An enterprise legacy industrial control system (ICS) cannot support multi-factor authentication (MFA) or local encryption due to firmware limits. To meet compliance, security architects isolate the system on an air-gapped VLAN with jump box bastion hosts and continuous session recording. What type of control was deployed?

A. Preventive control
B. Compensating control
C. Deterrent control
D. Corrective control
Show answer and explanation

Correct answer: B. Compensating controls are alternative measures designed to satisfy a security requirement when a standard primary control (such as MFA or native encryption) is technically impossible or economically unfeasible.

Why the other options are wrong:

  • A. While network isolation acts preventively, the question specifically asks for the control type deployed because the primary control could not be implemented; this is the textbook definition of a compensating control.
  • C. Deterrent controls aim to dissuade adversaries psychologically; network isolation is an architectural mitigation.
  • D. Corrective controls remedy the damage or state after an attack has occurred; this architectural safeguard was applied proactively.
Question 10Medium

A Chief Information Security Officer (CISO) publishes a mandatory company-wide policy requiring all employees to lock their screens when leaving workstations, and imposes penalties for violations. Under which control category and type is this policy classified?

A. Technical / Detective
B. Managerial / Directive
C. Operational / Corrective
D. Physical / Deterrent
Show answer and explanation

Correct answer: B. Policies and governance rules authored by leadership are Managerial controls. When a rule specifies required behavior and compliance mandates, it functions as a Directive control.

Why the other options are wrong:

  • A. Technical controls are implemented through software configurations (such as an automated screen lock timeout GPO), whereas this question addresses the written policy itself.
  • C. Operational controls are day-to-day human execution processes (e.g., security guard rounds), not high-level governance policies.
  • D. Physical controls pertain to barriers and doors; a written acceptable use policy is administrative/managerial.
Question 11Medium

An API gateway validates incoming JSON Web Tokens (JWT) signed by an identity provider, inspects the embedded "roles" claim, and rejects a client attempting to write to an administrative endpoint. Which distinct security function is being enforced at the endpoint gate?

A. Identification
B. Authentication
C. Authorization
D. Accounting
Show answer and explanation

Correct answer: C. Evaluating the embedded role claim to permit or deny access to a specific administrative endpoint is Authorization. Authentication verified the token signature earlier, but checking permissions for a specific action is authorization.

Why the other options are wrong:

  • A. Identification is the presentation of an identity claim (such as a username or subject claim).
  • B. Authentication verifies the validity of the identity claim (the token signature), but inspecting what that authenticated identity is allowed to do is authorization.
  • D. Accounting records the transaction event into an access log for audit trails.
Question 12Medium

A security auditor discovers that an application relies on MD5 to generate checksums for sensitive software binaries. What cryptographic vulnerability is the auditor most concerned about?

A. Lack of key escrow support
B. Collision vulnerability
C. Ciphertext-only cryptanalysis
D. Lack of forward secrecy
Show answer and explanation

Correct answer: B. MD5 is vulnerable to hash collisions, where an adversary can generate two distinct files that produce the exact same MD5 digest, allowing malicious code to masquerade as legitimate software.

Why the other options are wrong:

  • A. Key escrow relates to symmetric and asymmetric encryption keys, not unkeyed cryptographic hash algorithms.
  • C. Ciphertext cryptanalysis applies to encryption ciphers, whereas MD5 is a one-way hashing function.
  • D. Forward secrecy is a property of ephemeral session key exchange protocols, not static hash functions.
Question 13Medium

When generating a digital certificate for a public web application, what file does the server administrator create and submit to the Certificate Authority (CA)?

A. The server’s private key in raw PEM format
B. Certificate Revocation List (CRL)
C. Certificate Signing Request (CSR)
D. OCSP Response token
Show answer and explanation

Correct answer: C. A Certificate Signing Request (CSR) contains the server’s public key and identity information (Common Name, Subject Alternative Names, organization), which is signed by the applicant and submitted to the CA.

Why the other options are wrong:

  • A. The private key must never leave the server or be shared with the CA; sharing the private key completely undermines PKI trust.
  • B. A CRL is published by the CA to list revoked certificates, not created by the applicant.
  • D. An OCSP response is provided by an OCSP responder to certify the real-time validity of a certificate.
Question 14Medium

Which certificate validation technology improves performance and user privacy by having the web server periodically fetch a timestamped, CA-signed validity proof and attach it directly to the TLS handshake?

A. Certificate Revocation List (CRL)
B. Online Certificate Status Protocol (OCSP) Stapling
C. Key Escrow Verification
D. Public Key Pinning (HPKP)
Show answer and explanation

Correct answer: B. OCSP Stapling (RFC 6066) allows the web server to query the CA’s OCSP responder itself at set intervals and "staple" the cached, signed revocation status directly to the TLS handshake, reducing latency and preventing the CA from seeing user browsing habits.

Why the other options are wrong:

  • A. CRLs require clients to download large lists of revoked serial numbers, causing significant bandwidth and caching delay.
  • C. Key escrow stores private keys for decryption recovery; it does not validate certificate revocation.
  • D. HTTP Public Key Pinning (HPKP) was a deprecated security header to pin specific keys, not a revocation status mechanism.
Question 15Medium

A security engineer is configuring a TLS 1.3 web cipher suite. Which cryptographic feature ensures that even if the web server’s long-term private key is compromised in the future, past recorded encrypted session traffic cannot be decrypted?

A. Perfect Forward Secrecy (PFS)
B. Asymmetric Key Escrow
C. Digital Signature Algorithm (DSA)
D. Authenticated Encryption with Associated Data (AEAD)
Show answer and explanation

Correct answer: A. Perfect Forward Secrecy (PFS) generates unique, ephemeral session keys for each communication session (such as using ECDHE). Because session keys are discarded and not derived from the server’s permanent private key, a future compromise of the private key cannot retroactively decrypt past sessions.

Why the other options are wrong:

  • B. Key escrow creates a backup of private keys for authorized third-party decryption, which increases retrospective risk rather than preventing it.
  • C. DSA is an asymmetric algorithm used for digital signatures, but it does not inherently guarantee session ephemeral key forward secrecy.
  • D. AEAD ciphers (like AES-GCM) provide confidentiality and integrity simultaneously, but AEAD alone does not prevent past traffic decryption if session key exchange lacked forward secrecy.
Question 16Medium

An organization establishes a policy requiring at least three out of five designated security officers to present their physical smart cards and passphrases simultaneously to unlock the root master encryption key. Which concept does this illustrate?

A. Dual-control authorization
B. Split knowledge / M-of-N control
C. Zero-knowledge proof
D. Key rotation schedule
Show answer and explanation

Correct answer: B. M-of-N control (a form of split knowledge and secret sharing) mandates that out of N authorized individuals, at least M of them must collaborate to reconstruct the cryptographic key or authorize a critical action.

Why the other options are wrong:

  • A. Dual-control specifically requires two individuals; M-of-N is the precise multi-party threshold model described (3 of 5).
  • C. A zero-knowledge proof allows a party to prove possession of a secret without disclosing the secret itself.
  • D. Key rotation is the periodic replacement of active keys with new keys based on a cryptographic cryptoperiod.

Questions 17 to 20: scenarios

Scenario questions describe a situation and ask for the BEST action. Identify the problem first, then pick the answer that fixes the root cause rather than a symptom.

Question 17Scenario

During an emergency maintenance window, an engineer pushes a core router routing table update without going through the formal Change Advisory Board (CAB) review. The update corrupts internal BGP routes, causing a total intranet outage. When management demands immediate recovery, the team discovers no previous configuration state was preserved. Which two change management elements failed?

A. Security impact analysis and Request for Proposal (RFP)
B. Service Level Agreement (SLA) and Acceptable Use Policy (AUP)
C. Testing / approval process and documented backout plan
D. Asset inventory tagging and physical access control
Show answer and explanation

Correct answer: C. Bypassing the CAB skipped formal impact analysis, sandbox testing, and authorized sign-off. Furthermore, failing to preserve the previous stable configuration demonstrates the total absence of a backout/rollback plan.

Why the other options are wrong:

  • A. An RFP is a procurement bidding document for purchasing vendor products, not a technical change control step.
  • B. SLAs are vendor uptime metrics and AUPs govern acceptable end-user computer behavior; neither manages router configuration changes.
  • D. Asset tagging tracks inventory hardware; the failure was an administrative and operational change control failure.
Question 18Scenario

An attacker compromises an internal marketing workstation via a spear-phishing email. When attempting to pivot laterally across the corporate network using Pass-the-Hash to reach the HR payroll database, the attacker is immediately blocked because each subnet and application workload requires separate, continuous certificate-based identity validation and software-defined boundary checks. Which architecture prevented this lateral movement?

A. Edge stateful perimeter firewall
B. Zero Trust microsegmentation
C. Split-tunnel VPN configuration
D. Network Address Translation (NAT)
Show answer and explanation

Correct answer: B. Zero Trust microsegmentation divides networks into granular, secure zones and enforces individual identity verification and policy checks between workloads, effectively blocking lateral movement even after a perimeter workstation is compromised.

Why the other options are wrong:

  • A. A perimeter firewall inspects traffic entering or leaving the enterprise edge, but typically permits unrestricted internal lateral traffic once inside.
  • C. Split-tunnel VPN directs remote client Internet traffic away from corporate VPN concentrators, which does not prevent internal lateral propagation.
  • D. NAT translates private IP addresses to public IPs for external routing; it is not a Zero Trust containment safeguard.
Question 19Scenario

A security operations team discovers that the private key of an intermediate Certificate Authority (CA) was exfiltrated by an advanced persistent threat (APT). What urgent action must the root CA administrator take to prevent attackers from issuing trusted fraudulent certificates?

A. Rotate the web server public certificates using automated ACME scripts
B. Revoke the intermediate CA certificate and publish the updated CRL / OCSP status immediately
C. Extend the root CA expiration validity period by five years
D. Re-issue all client personal authentication certificates using MD5 checksums
Show answer and explanation

Correct answer: B. When an intermediate CA’s private key is compromised, the root CA must immediately revoke that intermediate certificate and publish the revocation via CRLs and OCSP. This invalidates the entire sub-tree of certificates issued by that compromised intermediate CA across all trusting systems.

Why the other options are wrong:

  • A. Rotating endpoint certificates does nothing to stop the adversary from continuing to generate new fraudulent certificates using the compromised intermediate CA key.
  • C. Extending the root CA’s lifetime has no impact on invalidating the compromised intermediate key.
  • D. MD5 is thoroughly broken and deprecated; using MD5 introduces severe cryptographic collision vulnerabilities.
Question 20Scenario

Alice needs to send a highly sensitive confidential contract to Bob over an untrusted network. The system must guarantee that ONLY Bob can read the contract, and Bob must have mathematical certainty that Alice was the author and that the content was unmodified. How should Alice’s software cryptographically process the message?

A. Encrypt the message with Alice’s public key, then sign the hash with Bob’s private key
B. Encrypt the message with Bob’s public key, and sign the message hash with Alice’s private key
C. Encrypt the message with Bob’s private key, and sign the message hash with Alice’s public key
D. Hash the message using SHA-256 and encrypt the payload with a shared pre-shared key (PSK)
Show answer and explanation

Correct answer: B. To achieve confidentiality, Alice encrypts with Bob’s public key (ensuring only Bob’s private key can decrypt it). To achieve authenticity, integrity, and non-repudiation, Alice signs the message hash with her own private key (which Bob can verify using Alice’s public key).

Why the other options are wrong:

  • A. Alice cannot sign with Bob’s private key (she does not possess it), and encrypting with Alice’s public key means only Alice could decrypt it.
  • C. Alice does not possess Bob’s private key, and signing with a public key is cryptographically invalid.
  • D. A shared pre-shared key does not provide non-repudiation because either party could have created the ciphertext, and it does not use public key cryptography.
